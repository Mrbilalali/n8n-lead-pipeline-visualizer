# n8n Lead Pipeline Visualizer

Interactive demo by **Bilal Ali — AI Automation Expert**.

Watch a fictional lead flow through an AI lead pipeline in **42 seconds**:

1. **Capture** — lead arrives via web form / webhook
2. **Enrich** — company size, industry, website lookups
3. **Score** — AI score with reason chips
4. **Route** — lead lands in CRM, routed to a sales rep with a priority tag
5. **Follow up** — personalized SMS + email sequence preview (queued, not sent)

Clearly labeled as a **scripted simulation**: fictional lead, no real data leaves the page, no real calls or messages are placed.
